CAMISETA DA VARZEA

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o terminal nessa pasta.
4. Rode: npm install
5. Renomeie .env.local.example para .env.local
6. Coloque no .env.local a URL e a chave anon do seu projeto Supabase.
7. Rode: npm run dev
8. Abra: http://localhost:3000

O banco Supabase já deve ter sido criado usando o SQL das etapas anteriores.

A pasta já contém:
- Next.js
- Tailwind
- conexão Supabase
- primeira página da loja
